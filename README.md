## 🌟 Key Features

- **Rich Dark-Mode Aesthetic:** Built with a custom HSL design system, glassmorphic header, subtle ambient radial glows, and interactive hover micro-animations.
- **Interactive Certificate Lightbox Modal:** In-page modal viewer allowing visitors to preview high-resolution credential documents and badges with direct verification jump links (Credly, DataCamp, Udacity, EF SET).
- **Dynamic Age Calculation:** Real-time JavaScript computation tracking age dynamically from birthdate (`2001-01-01`), eliminating manual update requirements.
- **Social & OpenGraph Ready:** Handcrafted 1200×630 OpenGraph and Twitter Card preview assets (`assets/img/og-preview.png`) ensuring branded cards appear when shared on LinkedIn, WhatsApp, and X.
- **Lightweight & High-Performance:** Pure Vanilla CSS and JavaScript with zero external frameworks or heavy runtime bundles. Fast Core Web Vitals (LCP, INP, CLS).

## 🚀 Running Locally

Because this project is built entirely on vanilla web standards, you can preview it immediately without installing any build tools:

```bash
# Clone the repository
git clone https://github.com/Mazen-Shams/portfolio.git
cd portfolio

# Open directly in your default browser
start index.html
```

Or run a local static server with Python:
```bash
python -m http.server 8000
# Open http://localhost:8000
```
